Selected work

Magetender

Unity (URP) / C# / 2025 – present

Magetender is a 2D fantasy game about a wizard-school dropout running a bar: mixing magical drinks to match a customer's mood, and defending the bar with a quick-time spell system when an order goes badly. I built it over six months with an interdisciplinary team, Team TAAAZED, handling systems design, UI, and every accessibility feature end to end.

Design & systems

  • Designed the quick-time combat manager: input sequences, hit/miss resolution, and per-enemy behavior.
  • Built a JSON-driven monster and content pipeline, so new enemies and dialogue can be added without touching code.
  • Rebuilt the game's Fantasy Meter UI as a Shader Graph-based shader that scales cleanly at any resolution, replacing an older sprite-swap version.
  • Set up a persistent AudioManager so combat music transitions cleanly between game states.

Accessibility & player-centered design

Six months of interdisciplinary work meant constantly asking who our players actually were and what they needed from the interface, not just what looked good. I owned accessibility for Magetender end to end.

  • Localized the game into Spanish and Arabic (interface and subtitles), catching and fixing translation issues along the way.
  • Designed full controller support, including a custom virtual-mouse system for menu navigation without a mouse.
  • Built colorblind-accessible UI and gameplay feedback.
  • Designed one-handed and touch-friendly controls, and re-tested them by hand through every new feature and version to confirm the game stayed playable one-handed.
  • Led sound accessibility for the game.

Every one of these went through repeated rounds of testing as the game changed, not a single pass at launch.
